# your-own-jultron

Experimental personal computing system exploring the intersection of artificial intelligence, embedded devices, real-time interaction and autonomous execution.

![Holographic core](website/jarvis.png)

**Live:** <https://yellowgreen-goldfinch-897482.hostingersite.com/>

## Website

Static engineering lab with a WebGL core, execution traces, architecture records and benchmarks. It has no build step or runtime dependencies.

```bash
python3 -m http.server 8000 --directory website
```

Then open <http://localhost:8000>.

## Repository status

This repository currently holds the public website only. Traces shown on the site are illustrative until runtime instrumentation ships.
